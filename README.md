## 🚀 Новые возможности форка

- 🎛️ **Настройка через UI (Config Flow)** — интеграция добавляется и конфигурируется через стандартный интерфейс Home Assistant (**«Настройки» → «Устройства и интеграции»**), больше не нужно вручную редактировать `configuration.yaml`.
- 🔗 **Умное распознавание ссылок** — достаточно просто вставить ссылку из кнопки «Поделиться» приложения «Московский транспорт» (`https://moscowapp.mos.ru/l/...`), полную ссылку из браузера или UUID. Интеграция сама вытащит нужный ID остановки.
- 🚏 **Автоопределение названия и маршрутов** — при вводе ссылки автоматически подтягивается реальное название остановки и список всех проходящих через неё маршрутов с удобным мультивыбором.
- ⚙️ **Изменение параметров на лету (Options Flow)** — кнопка **«Настроить»** на карточке интеграции позволяет в любой момент изменить отслеживаемые маршруты и интервал обновления без перезагрузки Home Assistant.
- 📊 **Готовая Lovelace-карточка табло** — стильная карточка для панели управления с номерами маршрутов, таймером до прибытия и индикатором живой GPS-телеметрии.
- 🏛️ **Интеграция в реестр устройств** — каждая остановка регистрируется как отдельное устройство со своими сенсорами.
- 🔄 **Обратная совместимость** — старые конфигурации из `configuration.yaml` автоматически импортируются в UI при старте.

## 📲 Как получить ссылку на остановку

<img src="https://raw.githubusercontent.com/egmen/moscow_transport/main/assets/transport_app_screenshot.jpg" width="160px" align="right" />

1. Откройте мобильное приложение **«Московский транспорт»** ([Google Play](https://play.google.com/store/apps/details?id=ru.mosgorpass) / [App Store](https://apps.apple.com/us/app/moscow-transport/id1227002793)).
2. Найдите нужную остановку на карте и откройте её карточку.
3. Нажмите кнопку **«Поделиться»** (иконка в правом верхнем углу) и скопируйте ссылку.
4. Вы получите ссылку вида `https://moscowapp.mos.ru/l/S0G3Qb` (или `https://moscowapp.mos.ru/stop?id=...`).
5. **Всё!** Эту ссылку можно сразу вставлять в диалог настройки в Home Assistant — открывать сайт в браузере не требуется.

## 🛠️ Установка и настройка

### 1. Установка через HACS

1. Откройте **HACS** → **Интеграции**.
2. Нажмите меню с тремя точками в правом верхнем углу → **Пользовательские репозитории**.
3. В поле репозитория укажите:
   ```
   https://github.com/d3890666/moscow_transport
   ```
   Категория: **Интеграция**.
4. Найдите **Moscow Transport** в списке, нажмите **Загрузить** (выберите версию `24.11.3` или новее) и перезагрузите Home Assistant.

---

### 2. Добавление остановки через UI

1. Перейдите: **Настройки** → **Устройства и интеграции** → **Добавить интеграцию**.
2. В поиске найдите **Moscow Transport**.
3. Вставьте скопированную ссылку на остановку (или её UUID).
4. На следующем шаге отобразится название остановки и список маршрутов:
   - Отметьте нужные маршруты (если ничего не выбрано — отслеживаются все).
   - При необходимости задайте понятное название (например, *«Остановка у дома»*).
5. Нажмите **Отправить**. Будет создано устройство остановки со всеми сенсорами.

> [!TIP]
> Чтобы добавить другие остановки (у работы, у метро и т.д.), просто повторите процедуру добавления интеграции. Каждая остановка будет отдельным устройством.

---

### 3. Изменение настроек (Options Flow)

Чтобы изменить отслеживаемые маршруты или частоту опроса:
1. Перейдите в **Настройки** → **Устройства и интеграции** → найдите добавленную остановку.
2. Нажмите кнопку **«Настроить»**.
3. Измените список маршрутов или интервал опроса (от 15 до 600 секунд) и нажмите **Отправить**. Изменения применятся мгновенно.

## 📊 Карточка онлайн-табло для Lovelace

В состав интеграции входит карточка **Moscow Transport Board** (`custom:moscow-transport-card`):

```yaml
type: custom:moscow-transport-card
entity: sensor.9_ya_ul_sokolinoy_gory_12_moscow_transport
title: Остановка у дома
max_items: 5
```

### Подключение ресурса карточки:
Если карточка не определяется автоматически, добавьте ресурс в **Панели управления** → **Три точки** → **Изменить панель** → **Управление ресурсами**:
- **URL:** `/moscow_transport/moscow-transport-card.js`
- **Тип:** Модуль JavaScript

## ⚙️ Настройка через configuration.yaml (Legacy)

Если вы предпочитаете настраивать через YAML, старый синтаксис поддерживается и автоматически мигрирует в UI-записи:

```yaml
sensor:
  - platform: moscow_transport
    name: К метро
    stop_id: 86f6869e-59dc-44a9-8575-3cee948c6f4f
    routes:
      - 83
      - 680
```
