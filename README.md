# Moscow Transport для Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/custom-components/hacs)
![GitHub actions](https://github.com/egmen/moscow_transport/actions/workflows/validate.yml/badge.svg)

Интеграция для Home Assistant для отображения онлайн-табло и времени прибытия автобусов, электробусов и трамваев к остановкам в Москве по данным «Московского транспорта» (живая GPS-телеметрия и расписание).

---

## ✨ Возможности

- 🚀 **Современная настройка через UI** — добавление и управление интеграцией прямо в интерфейсе Home Assistant («Настройки» → «Устройства и интеграции»).
- 🔗 **Умный ввод ссылки** — достаточно вставить ссылку остановки из приложения («Поделиться»), длинную ссылку с сайта или UUID остановки. Интеграция сама извлечет нужный ID и определит остановку.
- 🚏 **Автоопределение маршрутов** — при добавлении остановки автоматически подтягиваются все реально проходящие маршруты с удобным мультивыбором.
- ⚙️ **Изменение настроек на лету (Options Flow)** — кнопка «Настроить» на карточке интеграции позволяет менять отслеживаемые маршруты и частоту обновления без перезапуска Home Assistant.
- 📱 **Современная карточка для Lovelace дашборда** — стильное табло прибытия с номерами маршрутов, таймером до прибытия и индикатором живой GPS-телеметрии.
- 🔄 **Полная обратная совместимость** — поддержка конфигурации через `configuration.yaml` с автоматическим импортом.

## 📲 Как получить ссылку на остановку

<img src="https://raw.githubusercontent.com/egmen/moscow_transport/main/assets/transport_app_screenshot.jpg" width="160px" align="right" />

1. Откройте приложение **«Московский транспорт»** ([Google Play](https://play.google.com/store/apps/details?id=ru.mosgorpass) / [App Store](https://apps.apple.com/us/app/moscow-transport/id1227002793)).
2. Найдите на карте нужную остановку и откройте её карточку.
3. Нажмите кнопку **«Поделиться»** (иконка шеринга вверху) и скопируйте ссылку.
4. Получится ссылка вида `https://moscowapp.mos.ru/l/S0G3Qb` (или `https://moscowapp.mos.ru/stop?id=86f6869e-59dc-44a9-8575-3cee948c6f4f`).
5. **Всё!** Эту ссылку можно сразу вставлять в форму добавления интеграции в Home Assistant.

## 🛠️ Настройка через UI (Рекомендуется)

1. Перейдите в Home Assistant: **Настройки** → **Устройства и интеграции** → **Добавить интеграцию**.
2. В поиске введите **Moscow Transport**.
3. Вставьте скопированную ссылку на остановку (или её UUID).
4. Интеграция проверит остановку и на следующем шаге покажет её реальное название и список всех маршрутов:
   - Выберите маршруты, которые вам нужны (или оставьте пустым, чтобы отслеживать все).
   - При желании задайте понятное название (например, *«Остановка у дома»*).
5. Нажмите **Отправить**. Будет создано устройство остановки со всеми сенсорами.

> [!TIP]
> Чтобы в любой момент изменить список маршрутов или интервал опроса, нажмите кнопку **«Настроить»** на карточке интеграции в списке устройств.

## 📊 Карточка онлайн-табло для Lovelace

В состав интеграции входит готовая карточка **Moscow Transport Board** для панели управления Home Assistant:

```yaml
type: custom:moscow-transport-card
entity: sensor.9_ya_ul_sokolinoy_gory_12_moscow_transport
title: Остановка у дома
max_items: 5
```

### Подключение ресурса карточки:
Если карточка не отображается автоматически, добавьте ресурс в **Панели управления** → **Три точки** → **Изменить панель** → **Управление ресурсами**:
- **URL:** `/moscow_transport/moscow-transport-card.js`
- **Тип:** Модуль JavaScript

## ⚙️ Настройка через configuration.yaml (Legacy)

Интеграция по-прежнему поддерживает добавление через `configuration.yaml` (записи автоматически импортируются в UI):

```yaml
sensor:
  - platform: moscow_transport
    name: От метро
    stop_id: a6477b89-72c7-4359-8286-3f148874d653
    routes:
      - 733
      - 733к
      - 688
  - platform: moscow_transport
    name: К метро
    stop_id: 86f6869e-59dc-44a9-8575-3cee948c6f4f
```
